# 감성 로또 추첨기

번호를 기다리는 잠깐의 설렘을 담은 브라우저 추첨기입니다. 오늘의 운세로 시작해 공과 플랩의 움직임, 흐르는 배경, 가벼운 손뼉 소리와 함께 번호를 뽑습니다.

## 실행

저장소 전체를 다운로드하고 압축을 푼 뒤 `로또추첨.html`을 브라우저에서 여세요. JavaScript와 CSS 파일을 같은 폴더에 둡니다. 설치나 빌드가 필요하지 않습니다.

## 기능 · v0.4.0

- 첫 화면에서 타로·포춘 쿠키·물 운세·산통 제비 뽑기 선택
- 큰 바탕 카드 없이 펼친 네 버튼, 호버 확대·축소와 은은한 간접 조명
- 운세와 추첨 화면의 별도 라이트·다크 팔레트 및 색상 설정
- 선택한 타로 카드가 가운데로 이동하며 확대되고 3D로 회전
- 카드 뒤집기, 쿠키 열기, 물에 글자가 스며들기, 산통 흔들기와 제비 뽑기
- 오늘의 메시지를 확인한 뒤 번호 추첨으로 이동, 운세 화면으로 돌아가기

- 연금복권용 6자리: 0–9 숫자를 각각 추첨하며, 같은 숫자와 맨 앞의 0도 허용합니다. 조 번호는 포함하지 않습니다.
- 로또 6/45: 1–45 중 중복 없는 여섯 번호를 뽑아 오름차순으로 보여줍니다.
- 공 → 단색 플랩 → 색깔 공 전환과 한 방향으로 흐르는 그라데이션
- 라이트·다크별 배경, 강조색, 플랩 스타일 커스터마이징
- 가벼운 손뼉 느낌의 짧은 합성 효과음, 음량 조절, 음소거, 미리 듣기
- 추첨 중 부드럽게 섞이는 오로라 그라데이션
- 브라우저에 테마·추첨 방식·소리 설정 저장
- 작은 화면 및 동작 줄이기 설정 대응

## 구현

HTML/CSS, JavaScript, Web Audio API로 만들었습니다. 외부 라이브러리와 음원 다운로드가 없습니다. 짧게 겹치는 잡음으로 가벼운 손뼉 소리를 합성하고, 가까운 플랩 소리를 묶어 겹침을 줄입니다. v0.4.0에서는 피치를 두 반음 올리고 저음 성분을 완화했습니다. 소리는 버튼을 누른 뒤에만 활성화됩니다.

운세는 직접 작성한 일상 메시지 12개를 무작위로 보여주는 놀이입니다. 네 방식은 서로 다른 CSS 연출을 사용하며, 운세 내용은 번호 생성과 독립적입니다. 모든 데이터와 그림은 파일 안에 포함되어 있습니다.

번호 생성은 지원되는 환경에서 Web Crypto 난수를 사용합니다. 6/45는 부분 셔플로 중복을 방지하며, 애니메이션 전에 결과를 정합니다.

## 검증

Node.js가 있다면 `node --test tests/lottery.test.cjs`로 번호 범위·중복·정렬, 선행 0, 난수 경계, 효과음 파형을 확인할 수 있습니다.

## 프로젝트의 출발점

무작위 번호를 기다리는 과정 자체가 즐거울 수 있을까? 배경의 움직임, 형태 변화, 조용한 소리를 통해 작은 기대감을 만드는 개인 프로젝트입니다. 사용자 피드백을 바탕으로 연출을 반복해서 다듬습니다.
