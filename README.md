# 감성 로또 추첨기

번호를 기다리는 순간의 설렘을 담은 브라우저 추첨기입니다.
현재 추첨 방식은 연금복권용 0–9 숫자 여섯 자리이며, 로또 6/45 방식이 아닙니다.

## 실행

이 저장소를 다운로드한 뒤 `로또추첨.html`을 브라우저에서 여세요. 별도 설치나 빌드가 필요하지 않습니다.

## 기능

- 공 → 단색 플랩 → 색깔 공 전환
- 한 방향으로 흐르는 그라데이션 배경
- 라이트·다크 모드별 배경색, 강조색, 플랩 색상 설정
- 브라우저에 테마 저장 및 모드별 기본값 복원
- 작은 화면 대응 및 동작 줄이기 설정 지원

HTML/CSS와 JavaScript만으로 구성되어 있습니다.
